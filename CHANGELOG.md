# What's Changed

## 1.1.1 (23 October 2026)

- Added a line about me to the README, I'm an old school web developer and coder and this is how I build now.

## 1.1 (23 October 2026)

- The wizard owns up now if a step goes wrong, it used to say "All done" even when the copy had failed. If the games don't copy it stops there, cos the rest needs them.
- Two different games with the same file name both get sent now, the second one used to get left behind without a word. It goes in its own folder on the Deck (ES-DE shows it as a folder), and if it's the exact same file twice it only goes once.
- Steam favourites only touch their own shortcuts now. The first version tidied your other ones as well, hid EmuDeck's launchers and binned ones it thought were broken... that's gone, it swaps last time's favourites for this time's and leaves the rest how you had it. It picks the Steam account you last signed into, and works on a fresh account with no shortcuts yet too.
- The ES-DE art step finds games LaunchBox stores with a short path, and owns up if the Deck stops taking files.
- Version number's on the wizard's title bar now.
